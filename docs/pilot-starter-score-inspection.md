# Inspect a retained starter score

A private owner readout calls `StarterScoreInspection.summary` with an authenticated viewer, workflow reference and logical execution reference. Its scope provider checks the current viewer, source, workflow, epoch and retention permission before reading the local journal and again before disclosure. The provider independently resolves the original evaluation definition and the frozen population. Inspection has its own expiry. Reading a retained score requires no inference grant renewal.

The population digest is internal. Compute it over the ordered reserved cases in the original frozen manifest using records containing exactly `case_id`, `family_id`, `origin`, and `expected`. The expected metadata comes from the frozen owner adjudication, including target, adjudicator, adjudication time and evidence reference. Compute the input digest from the original opaque input handles and frozen decision-time fields. The inspection provider must establish both from authorized records independently of the result journal.

A scored summary exposes starter origin, freeze identity, population counts, model/comparator metrics and paired changes. Missing predictions remain missing and a zero automatic denominator has an undefined error rate. An absent score yields a frozen-unscored state. A prediction intent without a completed score yields a held state. Invalid journals and withdrawn disclosure permissions fail closed. This reader checks the local journal and its receipt relations. The actual source of inspection authority and the private Home wiring require separate integration.
