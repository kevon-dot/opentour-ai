# Starter case core: partial OPE-513

This slice implements private case review and a frozen-unscored worker receipt.
It does not install an OPE-538 confirmed-map producer, authoring entry, Slack UI,
scoring, independent population audit, or the OPE-515 normal-entry witness. A
guided map draft and a starter charter are not owner case confirmation.

Before-code acceptance mapping (current native OPE-513, OPE-505, OPE-515,
OPE-538, OPE-539 and the shared implementation contract):

| Local check | Native requirement | Positive and adverse evidence |
| --- | --- | --- |
| A1 | Current confirmed map and named owner | Trusted current confirmation port; missing producer, foreign owner/tenant, stale source, and revoked grant deny before storage |
| A2 | Case provenance and family semantics | Separate suggestion/origin/citations/inputs; reject unsupported fields/actions and contradictory template or duplicate lineage |
| A3 | Blind owner adjudication | Accept/edit/unresolved with actor, reason and time; idempotent action replay; stale revision and post-freeze changes deny |
| A4 | Seven-family no-model freeze | Seven proposed, six resolved, one unresolved/excluded, two development and four reserved; reopen unchanged without model or fit credentials |
| A5 | Whole-family protected reservation | Variants stay together; another pack cannot reserve an exposed or previously assigned family; repeated identical freeze returns the same receipt |
| A6 | Honest coverage | Per-branch/action independent reserved family counts; removing both missing-PO families leaves REVIEW at zero/uncovered; 100 paraphrases count one family |
| A7 | Actual worker handoff | Bind receipt to exact current starter IntakeWork; materialize/readback return frozen_unscored with no result digest and perform no scoring |

The confirmation port must hold current authority through each operation, and
return a confirmed, immutable map bound to the actual admitted run, tenant,
engagement epoch, policy and settings. The implementation has no permissive
default port. Generated test authorities establish software behavior only.
The port resolves the frozen baseline/comparator/scorer/abstention references
from current settings and denies owner mutations after output exposure. Optional
authoring, evaluated-model and evaluator identities stay separate from the owner;
their references do not grant inference permission. Missing model selections
produce no scores or result digest.
There is no prompt/training answer export API. Owner review retains private
targets; worker receipts expose only immutable references and counts.

Family equivalence is an owner-confirmed input, not a semantic inference by this
core. It additionally rejects conflicting template and identical-input family
assignments. Unresolved cases remain visible and excluded. New policy, label or
split versions require a successor and fresh protected families; this slice
does not automatically construct successors or reuse protected families.
The private ledger reconciles its freeze seal and all family/template/input
reservations on every projection. This detects partial restoration; it is not
an external anti-rollback witness for restoring the entire private directory.

Open acceptance: installed confirmed-map/current-owner producer; ordinary case
authoring and owner UI, source-case witness, scorer/evaluator-only answer access,
OPE-526 contamination audit, OPE-539 arithmetic and Home, and OPE-515 end-to-end
integration. Generated starter cases provide zero live recurrence, fit credit,
release evidence or customer accuracy.
