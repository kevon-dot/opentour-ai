# Exact categories in guided policy maps

A policy can declare an exact category on an authorized reference field. For example, `If invoice_category equals "carrier_freight" and po is present, FREIGHT.` compares the supplied decision-time value with the quoted token. The comparison is case-sensitive. Tokens begin with an ASCII letter and contain up to 64 letters, digits, underscores or hyphens. The `==` spelling is also supported. Distinct values on the same field are mutually exclusive. A missing or unrelated value never satisfies the equality.

The importer preserves the source passage. An owner can correct the predicate under the normal review grant, retaining the reason and attribution. Conflicting actions on overlapping conditions require precedence; unsupported text and impossible categorical conjunctions remain unresolved. The purchase-order and numeric operators keep their existing representations. The categorical fixture covers five invoice categories with a purchase order, a missing purchase order, and a mixed invoice without a matching rule. It exercises the private map boundary. The starter proposal, owner adjudication, scoring and Home paths have separate acceptance runs.
